# G-Tech AnthoFix Engineering Portal

An all-in-one hardware repair engine and web portal featuring AI diagnostics, video training hub, payment receipt audits, and automated communication modules built for high-performance engineering problem-solving.

---

## 🚀 Core Features

* **AI Diagnostics & Support:** Integrated intelligent diagnostic routing to troubleshoot complex hardware issues seamlessly.
* **Video Training Hub:** Structured technical modules and instructional videos for field engineers.
* **Secure Cloud Integration:** Real-time database syncing and user authentication powered by **Firebase**.
* **Automated Audits & Notifications:** Instant alert dispatching and verification tracking using **EmailJS** and **Termii**.

---

## 🛠️ Technology Stack

* **Frontend:** Responsive HTML5, CSS3, Modern JavaScript (Multi-page modular architecture)
* **Backend Services:** Firebase Firestore / Authentication
* **Notifications:** EmailJS, Termii SMS APIs

---

## 📄 Deployment & Setup

1. Clone or download the repository into your local workspace (such as Spck Editor).
2. Ensure your Firebase and EmailJS configuration keys are active in your JavaScript environment.
3. Push your code to your GitHub repository and verify your custom domain or GitHub Pages link under your repository settings.
